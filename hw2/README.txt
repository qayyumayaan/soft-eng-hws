To run the main code, run "npm start" in the terminal. Relative paths are needed only if the text file is within the module. Anything else requires the absolute path to the file. 

The goal of this file is to read a records text file, validate it, sort it by time, and put its output into a new file. 

The spelling of the colors must match exactly this set, but capitals or mixed case is accepted: ["black", "white", "red", "orange", "yellow", "green", "blue", "indigo", "violet", "gray", "pink"]


If npm start does not work, please run using node: 
node js/index.js

To run jasmine tests, please run:
npm test


Please review console_output.txt for the Jasmine console output.
